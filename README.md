# CookBook

Our family recipe collection. Each recipe is one Markdown file in the `recipes/` folder, built from [TEMPLATE.md](TEMPLATE.md). Allowed tag values are in [TAGS.md](TAGS.md).

**Browse the cookbook:** double-click `cookbook.html` to open it in your browser, with search and filters. After adding or editing a recipe, run `python build_cookbook.py` to refresh it.

File names use lowercase with hyphens, e.g. `recipes/chicken-tikka-masala.md`.
