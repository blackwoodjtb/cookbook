# Allowed Tags

Use these values in each recipe's front matter so recipes stay easy to sort and search. Add new values here first when you need one.

## meal_type
- Breakfast
- Lunch
- Dinner
- Dessert
- Snack
- Drinks
- Alcoholic drinks

## flavor
- Sweet
- Spicy
- Savory

## cuisine
- American
- Asian
- Chinese
- French
- Greek
- Indian
- Irish
- Italian
- Japanese
- Mediterranean
- Mexican
- Middle Eastern
- Thai

## complexity
- Easy
- Medium
- Hard

## Time format
Write prep_time and cook_time as minutes or hours, e.g. `15 min`, `1 hr 30 min`.
